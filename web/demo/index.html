Add Ask OLake to your docs

Ask OLake answers questions about OLake from its documentation and GitHub repositories, and links every claim to the page it came from. Try it with the button in the corner of this page.

The widget is one script. It adds a button and opens the assistant in a frame served from , so your site needs no API calls, no CORS setup and no new styles.

Script tag

Paste this line before </body>, or in <head>: it loads without blocking the page.

Plain iframe

Where a page cannot run third-party scripts, embed the assistant directly. Your content security policy needs this host in frame-src.

Docusaurus

Add the script to docusaurus.config.js. Docusaurus puts scripts entries in the page head; async keeps them from delaying rendering. The widget follows the site's light and dark theme.

Options

AttributeWhat it does
data-apiWhere the assistant runs. Defaults to the host the script came from.
data-titleHeading of the panel, for example your product name.
data-positionright (default) or left corner.
data-accentButton and link color as a hex value, for example #2e5aac.
data-opentrue opens the panel when the page loads.
data-timeoutSeconds to wait for an answer before offering a retry. Default 35.

Privacy

The widget sets no cookies and stores nothing in the visitor's browser. Questions go only to the assistant host, and answers are rendered as text, so nothing in an answer can run on your page.
